## 첫인상

올리브 녹색의 한반도가 청록 바다 위에 얹힌 지도는 즉각적으로 인상적이다. 일반적인 공공 대시보드처럼 보이지 않고, 손으로 만든 것처럼 의도적인 느낌이 난다. 청록 바다·올리브 육지·청록 primary·진남색 텍스트로 이루어진 팔레트는 일관성 있고 개성이 있다.

첫눈에 보이는 문제: 내비게이션 바 48px 안에 모드 토글·검색바·의원 수 뱃지·필터 드롭다운이 모두 들어가 있다. 데스크톱에서는 간신히 들어가지만, 375px 모바일에서는 겹침 충돌이 발생한다.

하단 힌트 "시/도를 클릭하면 선거구를 확인할 수 있습니다"는 낯선 인터랙션 패턴을 안내하는 중요한 역할을 한다. 좋은 판단이지만 대비가 낮아 놓치기 쉽다.

## 발견된 문제

### FINDING-001 — 심각: 375px 모바일 레이아웃 충돌
**페이지:** `/` (홈)

375px 뷰포트에서 국회의원/지자체장 모드 토글(absolute top-3 left-3)과 필터 컨트롤 바(전체지도 / 시도선택 / 선거구선택)가 같은 수직 공간에 물리적으로 겹친다. iPhone SE·소형 안드로이드 사용자는 두 컨트롤 중 어느 것도 안정적으로 사용할 수 없다.

**수정 방법:** 모바일에서 컨트롤을 수직으로 배치. 모드 토글이 전체 너비를 차지하고 필터 바가 아래로 내려오도록.

---

### FINDING-002 — 높음: 터치 타겟 44px 미달
**페이지:** 전체

핵심 인터랙티브 요소 다수가 Apple 44pt / Google 48dp 최소 기준 미달:
- 검색바 컨테이너: `h-8` = 32px
- 모드 토글 버튼(국회의원/지자체장): 약 28px
- 지도 줌 컨트롤(+/-): 28×28px
- 드롭다운(시/도선택, 선거구선택): 약 32px

터치 기기에서 핵심 내비게이션 탭 실패가 반복된다.

**수정 방법:** 모든 인터랙티브 컨트롤에 `min-h-[44px]` 적용.

---

### FINDING-003 — 중간: 폰트 패밀리 5개 로드
**페이지:** 전체

사용 중인 폰트: Inter, Manrope, Plus Jakarta Sans, Helvetica Neue, Lucida Console. 5개다. 3개도 많다. 폰트가 늘어날수록 번들 크기와 시각적 일관성 모두 나빠진다. `font-jakarta`(Plus Jakarta Sans)가 실질적인 주 폰트로 보이고, Inter와 Manrope은 이전 이터레이션의 잔재로 보인다.

**수정 방법:** `font-inter`, `font-manrope` className 사용 현황 감사 후 미사용 패밀리를 `_app.tsx` / `globals.css`에서 제거.

---

### FINDING-004 — 중간: 의원 기본정보 탭 빈 화면
**페이지:** `/members/[monaCode]` → 기본정보 탭

이메일·전화·사무실·성별·생년월일 다섯 행이 약 180px를 차지한다. 나머지 약 400px는 완전히 비어 있다. 소속 위원회·당선 횟수 등 데이터 모델에 존재하는 정보가 표시되지 않는다.

**수정 방법:** 기본정보 탭에 소속 위원회와 당선 횟수 표시. 빈 화면 상태에서는 안내 메시지 표시.

---

### FINDING-005 — 높음: 법안 목록 19,680px 무한 스크롤
**페이지:** `/members/[monaCode]` → 법안발의 탭

법안 목록이 페이지네이션·연도 그룹핑·필터 없이 전체를 한 번에 렌더링한다. 활동이 많은 의원의 경우 200건 이상이 된다. 감사한 의원의 경우 19,680px였다. 사이트에서 가장 심각한 UX 문제.

**수정 방법:**
- 단기: 20건 표시 후 "더 보기" 버튼
- 중기: 연도별 그룹핑, 상태 필터(계류중/가결/부결)
- 장기: v2 BillInsight 컴포넌트로 주요 법안 분야별 표면화

---

### FINDING-006 — 중간: 시맨틱 헤딩(H1-H6) 전무
**페이지:** 전체

어느 페이지도 H1-H6 요소를 사용하지 않는다. 전부 `<div>`와 `<p>`다. 스크린리더 내비게이션이 불가능하고, SEO에 불리하며, 보조 기술에 문서 구조가 보이지 않는다.

**수정 방법:**
- `/`: `<h1 className="sr-only">Vote the Boat — 국회의원 의정활동 확인</h1>` 추가
- `/members/[monaCode]`: 의원 이름을 `<h1>`으로
- `/members`: 페이지 제목을 `<h1>`으로

---

### FINDING-007 — 중간: 태블릿(768px) 지도 줌 너무 작음
**페이지:** `/` at 768px

768px에서 한반도가 청록 바다 한가운데 작게 표시되며 화면의 약 50%가 빈 바다다. 이 브레이크포인트에서 더 타이트한 기본 줌이 필요하다.

**수정 방법:** Leaflet 지도 초기화 시 반응형 줌 설정 — 현재 고정값 7에서 태블릿(768-1024px) 구간에서는 8로 조정.

---

### FINDING-008 — 낮음: 지자체장 지도에 정당 색상 범례 없음
**페이지:** `/` → 지자체장 모드

지자체장 지도가 정당별로 지역을 색칠하지만(파랑 = 더불어민주당, 적갈색 = 국민의힘) 범례가 없다. 처음 본 사용자는 색상 의미를 알 수 없고, 정당명은 호버 툴팁에서만 확인 가능하다.

**수정 방법:** 지도 좌하단에 소형 부동 범례 추가: `● 더불어민주당  ● 국민의힘` 등.

---

### FINDING-009 — 중간: GovernorMap `bringToFront()` z-order 버그
**파일:** `frontend/components/GovernorMap.tsx:193`

```js
mouseover: (e: any) => {
  e.target.setStyle({ fillOpacity: 0.88, weight: 2.5 });
  e.target.bringToFront();  // ← 문제
```

mouseover 핸들러 안에서 `bringToFront()`를 호출하면 매 호버마다 SVG z-index가 재정렬된다. 경계를 공유하는 지역에서 인접 지역이 앞으로 "튀어나와" 호버 상태가 깜빡이고 z-order가 깨진다. Leaflet에서 잘 알려진 함정.

**수정 방법:** `e.target.bringToFront()` 제거. `setStyle` 하이라이트만으로 충분.

---

### FINDING-010 — 낮음: 기초단체장 목록에 필터 없음
**페이지:** `/` → 지자체장 모드 → 시도 클릭

경기도 선택 시 31개 기초단체장이 스크롤 목록으로 표시되지만 검색·필터가 없다. 특정 시·군을 찾기 어렵다.

**수정 방법:** 목록 상단에 클라이언트 사이드 텍스트 필터 `<input>` 추가.
